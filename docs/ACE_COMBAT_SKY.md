# ACE COMBAT 8 天空适配

当前本地交付版本为 `0.1.0-ac8-sky.15`，使用恢复的原版 Cloudly 云层、大气、阴影和时序重建管线。开发分支为 `ace-combat-sky`，各次交付保留独立提交和版本标签。

## 使用

使用本地提供的 **bundled Fabric JAR**，替换旧 Caustica 模组即可。天空的体积纹理、着色器、原版月球和星空贴图、参数配方均直接包含在 JAR 中；无需额外天空资源包，也无需配置本机资源路径。模组直接读取 JAR 内的资源，不向配置目录解压天空包。

Minecraft 26.2、Fabric Loader 0.19.3 或更高版本、Fabric API，使用 Vulkan 后端。Caustica 本身的硬件要求仍适用，天空用于主世界。

简体中文设置中的“皇牌空战天空”提供：

- 开关：世界内直接生效；启用时在后台准备资源。
- 天空场景：机库、任务 3。所有场景均从 JAR 内加载，可在世界内切换；准备期间保留原场景，完成后自动切换。
- 云层渲染距离：范围 1–200 千米；云和卷云在各自有效上限的最后 5% 区间逐渐消失。距离归一化与光照、阴影的原生距离独立。

不提供云层精度或采样预算设置；追踪保留原版着色器的 128 次主循环、256 次含空区循环上限，不经宿主改写。距离变更会重置云层历史。Minecraft 的时间、天气和月相作为宿主输入；单独的原始场景昼夜开关不再锁住宿主天体。

## 本版修复

- `.14` 用户运行日志确认任务 3 已完成资源准备和场景激活，但在第一帧分配阶段被非零清除声明拒绝；此前版本仍未实现任务 3 实际绘制。本版移除六张 AO 工作/历史纹理的多余初始化清除，保留原始 65 积分程序的完整预生成和周期发布，首帧不读取未生成的历史，也不以常量白图替代。
- 参数配方中的逻辑“且”按顺序检查全部条件并短路返回，不再忽略第三项；已确认该问题不解释 `.14` 本次首帧分配失败。
- 修复任务 3 在源包读取入口被旧的 `approximation=true` 强制条件拒绝。原版场景须声明 `originalPipeline=true` 与原版管线 manifest；保留旧近似源包的读取兼容。
- `.13` 的用户运行日志已确认任务 3 收到切换请求，但在读取源包时抛出异常，未开始资源生成；因此 `.13` 未解决任务 3 空白问题。本版修复该明确加载错误。
- 修正任务 3 内蓝噪声、月球和星空纹理的打包路径，将真实 mip 放在该场景纹理清单目录内，满足加载器的路径约束。
- 修复场景和开关只在进入世界时读取的问题；后台准备完成后，在同一帧切换云层、大气和直接光照，并重新开始云层历史积累。准备失败会记录具体错误并保留原场景。
- 编译和资源完整性检查不代表已经完成游戏内画面验收。
- 无实际地形、朝向虚拟地球的背景不再统一采样地平线切线颜色；使用随射线方向、相机高度变化的大气路径延拓，并保留云影和云合成。
- 实际追踪上限前执行距离渐隐，避免设置为 200 或 70 千米时仍按原始 250 千米范围淡出。
- 移除精度/预算选项与对应宿主字段，恢复原版追踪循环上限。
- 接入宿主雨雷强度、原版月盘和随宿主星角转动的真实星空 cubemap。雨区覆盖为显式宿主适配，其空间距离场与原版雨云着色分支配合使用；不能将其称为恢复了另一未提供的原始雨天天空预设。

## 资源与构建边界

本地私有 JAR 包含用户本机提取的资源。游戏资源、原始着色器和该私包不上传 GitHub 或公开 Actions。

公开源码和 CI 产物不包含这些私有资源，不能当作可直接体验 AC8 天空的完整包。私包构建使用 `-PcloudlyBundleInputRoot=<准备好的私有资源目录>`，资源只进入最终 JAR，不进入源码 JAR 或公开仓库。

本版按用户要求只做必要的编译和打包，没有追加测试、GPU 执行、图像识别或自动启动游戏。不能把编译成功描述为本版游戏画面、性能或与 AC8 视觉一致性已验收。

原始资源和管线恢复证据、具体集成边界见 [原版管线记录](AC8-original-pipeline.md)。

## 任务 3 场景来源

真实地图 `Map03/Mission003/Mission003_Common_Lit_Cloudly01` 的 Cloudly actor 引用 `CSP_Mission003_kanno260131` 与 `CVC_Mission003_kanno250202`。新增场景包含其独立天空参数、44 个云组件、14 张体积纹理及原始 mip，并使用任务 3 的原场景灯光强度和颜色。保留该场景启用的独立高层云细节及云层环境遮蔽，不能用机库预设改色替代。
