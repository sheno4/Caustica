# ACE COMBAT 8 天空适配

当前本地交付版本为 `0.1.0-ac8-sky.11`，使用恢复的原版 Cloudly 云层、大气、阴影和时序重建管线。开发分支为 `ace-combat-sky`，各次交付保留独立提交和版本标签。

## 使用

使用本地提供的 **bundled Fabric JAR**，替换旧 Caustica 模组即可。天空的体积纹理、着色器、原版月球和星空贴图、参数配方均直接包含在 JAR 中；无需额外天空资源包，也无需配置本机资源路径。模组直接读取 JAR 内的资源，不向配置目录解压天空包。

Minecraft 26.2、Fabric Loader 0.19.3 或更高版本、Fabric API，使用 Vulkan 后端。Caustica 本身的硬件要求仍适用，天空用于主世界。

简体中文设置中的“皇牌空战天空”提供：

- 开关：重新进入世界后生效。
- 云层追踪预算：每条视线主追踪循环的最大步数，范围 64–1024，默认 128；已有用户配置保留。高预算会增加显卡开销。
- 云层渲染距离：范围 1–200 千米；云和卷云在各自有效上限的最后 5% 区间逐渐消失。距离归一化与光照、阴影的原生距离独立。

预算和距离变更会重置云层历史。Minecraft 的时间、天气和月相作为宿主输入；单独的原始场景昼夜开关不再锁住宿主天体。

## 本版修复

- 无实际地形、朝向虚拟地球的背景不再统一采样地平线切线颜色；使用随射线方向、相机高度变化的大气路径延拓，并保留云影和云合成。
- 实际追踪上限前执行距离渐隐，避免设置为 200 或 70 千米时仍按原始 250 千米范围淡出。
- 原版追踪读取独立设置中的实际预算，不再借用旧近似渲染器的选项。
- 接入宿主雨雷强度、原版月盘和随宿主星角转动的真实星空 cubemap。雨区覆盖为显式宿主适配，其空间距离场与原版雨云着色分支配合使用；不能将其称为恢复了另一未提供的原始雨天天空预设。

## 资源与构建边界

本地私有 JAR 包含用户本机提取的资源。游戏资源、原始着色器和该私包不上传 GitHub 或公开 Actions。

公开源码和 CI 产物不包含这些私有资源，不能当作可直接体验 AC8 天空的完整包。私包构建使用 `-PcloudlyBundleInputRoot=<准备好的私有资源目录>`，资源只进入最终 JAR，不进入源码 JAR 或公开仓库。

本版按用户要求只做必要的编译和打包，没有追加测试、GPU 执行、图像识别或自动启动游戏。不能把编译成功描述为本版游戏画面、性能或与 AC8 视觉一致性已验收。

原始资源和管线恢复证据、具体集成边界见 [原版管线记录](AC8-original-pipeline.md)。
