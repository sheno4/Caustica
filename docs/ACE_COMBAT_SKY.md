# ACE COMBAT 8 天空适配

当前本地交付版本为 `0.1.0-ac8-sky.17`，使用恢复的原版 Cloudly 云层、大气、阴影和时序重建管线。开发分支为 `ace-combat-sky`，各次交付保留独立提交和版本标签。

## 使用

使用本地提供的 **bundled Fabric JAR**，替换旧 Caustica 模组即可。天空的体积纹理、着色器、原版月球和星空贴图、参数配方均直接包含在 JAR 中；无需额外天空资源包，也无需配置本机资源路径。模组直接读取 JAR 内的资源，不向配置目录解压天空包。

Minecraft 26.2、Fabric Loader 0.19.3 或更高版本、Fabric API，使用 Vulkan 后端。Caustica 本身的硬件要求仍适用，天空用于主世界。

简体中文设置中的“皇牌空战天空”提供：

- 开关：世界内直接生效；启用时在后台准备资源。
- 天空场景：机库、任务 3、任务 11。所有场景均从 JAR 内加载，可在世界内切换；准备期间保留原场景，完成后自动切换。
- 云层渲染距离：范围 1–200 千米；云和卷云在各自有效上限的最后 5% 区间逐渐消失。距离归一化与光照、阴影的原生距离独立。

不提供云层精度或采样预算设置；追踪保留原版着色器的 128 次主循环、256 次含空区循环上限，不经宿主改写。距离变更会重置云层历史。Minecraft 的时间、天气和月相作为宿主输入；单独的原始场景昼夜开关不再锁住宿主天体。

## 资源与构建边界

本地私有 JAR 包含用户本机提取的资源。游戏资源、原始着色器和该私包不上传 GitHub 或公开 Actions。

公开源码和 CI 产物不包含这些私有资源，不能当作可直接体验 AC8 天空的完整包。私包构建使用 `-PcloudlyBundleInputRoot=<准备好的私有资源目录>`，资源只进入最终 JAR，不进入源码 JAR 或公开仓库。

本版按用户要求只做必要的编译和打包，没有追加测试、GPU 执行、图像识别或自动启动游戏。不能把编译成功描述为本版游戏画面、性能或与 AC8 视觉一致性已验收。

原始资源和管线恢复证据、具体集成边界见 [原版管线记录](AC8-original-pipeline.md)。

## 任务 3 场景来源

真实地图 `Map03/Mission003/Mission003_Common_Lit_Cloudly01` 的 Cloudly actor 引用 `CSP_Mission003_kanno260131` 与 `CVC_Mission003_kanno250202`。新增场景包含其独立天空参数、44 个云组件、14 张体积纹理及原始 mip，并使用任务 3 的原场景灯光强度和颜色。保留该场景启用的独立高层云细节及云层环境遮蔽，不能用机库预设改色替代。

## 任务 11 场景来源

真实地图 `Map07/Mission011/Mission011_Common_Lit_Cloudly01` 引用 `CSP_ms11_251209` 与 `CVC_ms11_250814`。该场景包含 123 个云组件、16 张体积纹理与 160 个 mip；云组件使用源世界位置，不重复叠加编辑器父组变换。

独立配方包含 204 个密度生成阶段、3 个大气阶段及 32 个帧阶段。使用原始连续云厚检测、跳跃洪泛、10 次 SDF 归一化、标量模糊、二维切片和 mip 生成程序构建雨柱；原始场景启用状态不由宿主天气强制关闭。雨柱原生 BC4 分配在宿主以 R16F 保存原始编码值，云层 AO 仍使用已声明的 R32 浮点存储；这两项是存储适配，不能描述成与原版压缩分配完全相同。任务 11 尚未完成游戏内渲染与画面验收。
